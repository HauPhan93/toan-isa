# Toán ISA — English mode (contract for the translation agents)

The parent can switch the whole app to English in **Góc phụ huynh → Ngôn ngữ / Language** (user request: a
Vietnamese child learns the same SGK Kết nối tri thức maths in English, like a bilingual school). Vietnamese
stays the default and must keep working exactly as before.

## How it works

`js/util.js` (loaded first) decides the language once, at load: `U.LANG` is `'vi'` or `'en'`, `U.EN` is
`true` in English. Changing the language reloads the app, so every string can be chosen while the content is
built. `?lang=en` in the URL forces English (use it for tests).

```js
const L = U.L;                 // put this at the top of the file's IIFE
L('Vietnamese text', 'English text')   // → the text for the current language (Vietnamese when English is missing)
U.readEN(345)                  // → "three hundred and forty-five" (British style, "point" for decimals)
```

## Rules for content files (`js/content/lopN.js`, `dethi*.js`)

1. Every string the child sees or hears becomes `L(vi, en)`: lesson `title`, `story`, `book` (`Bài 12` →
   `Lesson 12`), topic titles, learn cards (title, text, bullets…), `prompt`, `hint`, `explain`, choice option
   texts, units written as words, labels passed to visuals, exam labels. Template literals too:
   ``L(`Có ${F(a)} quả táo`, `There are ${F(a)} apples`)``. For an array of templates you may instead write
   `const ADD_T = U.EN ? [ …English… ] : [ …Vietnamese… ]` — the two arrays must have the same length and
   the same order, each entry taking the same arguments (and `ok` filters must stay the same).
2. **Never change the random-number sequence or logic.** Do not call `rng` / `R` / `P` / `U.pick` … inside an
   `L(...)` argument; compute the value first, then use it in both strings. Do not reorder, add or remove `rng`
   calls, `U.choices` calls or answers. Ids (`g3-c2-b14`), numbers, answers, `correct` indexes, visual params
   that are numbers stay exactly the same. The Vietnamese text must stay byte-for-byte what it is now.
3. **Maths notation stays as in the SGK in both languages:** `U.fmt` (12 345, 3,5), signs `+ − × :`,
   `< > =`, fractions, unit symbols (kg, m, cm, l, ml, km², °C), the blanks `??` / `…` / `?`. Do not touch
   `U.fmt` or number formatting.
4. English style: simple, warm, natural **British English** for 6–11-year-olds (Cambridge Primary Maths
   wording: "ones, tens, hundreds", "column addition", "metre", "litre", "colour", "maths"). Short sentences.
   Address the child as "you". No over-the-top praise ("genius", "amazing", "awesome", "perfect") — only calm
   encouragement ("Well done!", "That's right.", "Try again.", "Good try."). Keep the Vietnamese names
   (An, Bình, Mai…) as they are. Vietnamese money stays "đồng" → in English write "dong" (e.g. "5 000 dong").
   Vietnamese measurement words → English words (ki-lô-gam → kilograms, xăng-ti-mét → centimetres, giờ → hours,
   phút → minutes, ngày → days, tuần → weeks, tháng → months, năm → years, Thứ Hai → Monday…).
   Maths terms: số hạng → addend, tổng → sum, số bị trừ → minuend, số trừ → subtrahend, hiệu → difference,
   thừa số → factor, tích → product, số bị chia → dividend, số chia → divisor, thương → quotient, số dư →
   remainder, chu vi → perimeter, diện tích → area, phân số → fraction, tử số → numerator, mẫu số → denominator,
   số thập phân → decimal, tỉ số phần trăm → percentage, "Đặt tính rồi tính" → "Set out and calculate"
   (column method), "Tính nhẩm" → "Mental maths", "Tìm x / số thích hợp" → "Find the missing number",
   "Đúng / Sai" → "True / False", "Khoanh vào chữ đặt trước câu trả lời đúng" → "Circle the letter of the
   correct answer".
5. Lessons that are about the **Vietnamese language of numbers** (đọc số / viết số in words, "mười / mươi /
   mốt / lăm / linh", "chục"): in English, read and write numbers in English words with `U.readEN(n)` (or your
   own correct English), use "tens and ones". Make wrong options plausible English mistakes ("fourteen" vs
   "forty"). Keep the same answer kind, the same number of options and the same `correct` index logic.
   If a Vietnamese reading helper is used to build the answer (e.g. `readVN(n)`), use `U.EN ? U.readEN(n) : readVN(n)`.
6. Where code tests a Vietnamese string (`if (opt === 'Đúng')`, regexes on text), keep both languages working.
7. Comments stay English. Do not edit files you do not own. Do not reformat lines you do not change.

## Check your work

The preview server runs at `http://localhost:8130`. If you have the built-in browser tools
(`mcp__Claude_Browser__*`), open **your own tab** with `tabs_create` and pass that `tabId` to every call (other
agents use other tabs at the same time; never touch a tab you did not create, never use `resize_window`, close
your tab at the end). Run:

- `http://localhost:8130/test-content.html?grade=N&lang=en` and `…?grade=N&lang=vi` — both must report 0 errors.
- `…/test-content.html?show=<lesson id>&lang=en` prints sample questions of one lesson: read a sample of every
  lesson in English and check that the English is correct, natural and says the same thing as the Vietnamese.
- After loading, `get_page_text` (or `javascript_tool`) to read the results; a syntax error shows as
  "no lopN" / a console error (`read_console_messages`).
- A quick Vietnamese check that nothing changed: the Vietnamese prompts must be identical to before
  (compare a few samples with `git diff`).

If the browser tools are not available, review the diff with great care instead (balanced quotes/backticks,
every `L(` has two arguments) and say so in the report.
